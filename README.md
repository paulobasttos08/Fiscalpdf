# FiscalPDF

1. Envie NF-e/NFC-e em PDF.
2. Clique em **Analisar PDFs**.
3. O sistema analisa página por página e identifica o CNPJ do emitente.
4. Cada CNPJ aparece com seu próprio botão **Baixar PDF**.
5. Só as páginas daquele CNPJ entram no arquivo baixado.

A versão atual não baixa nada automaticamente durante a análise. O download acontece somente quando o usuário clica no botão do CNPJ desejado.
